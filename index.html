Anthropic 在 Claude Code 加入新規則：不准重製特定既有遊戲，就算改名、自稱原創也不行

有開發者 10/30 發現 Claude Code 的提示規則在 10/27 多了一條：可以做原創遊戲、類型遊戲，或用使用者自己的設計與素材做遊戲，但不得重製某款特定的既有遊戲，即使改名或聲稱原創也一樣，而且使用者無法關閉。Anthropic 隨後證實是在 Opus 5.5 上加了兩句提示，理由是用 Claude 侵害他人 IP 違反使用政策。背景是近幾個月 AI 快速仿作遊戲氾濫，已有工作室因怕 demo 被拿去仿製而取消公開試玩，開發者也向 Valve 施壓要求說明如何防堵。

點評這是 AI 工具商第一次在產品層直接回應遊戲仿作問題，對獨立團隊是好消息；但 Game Developer 也點出，提示詞規則容易被話術繞過，工具也無從判斷素材是否真屬使用者，公開試玩前的防仿作策略仍得自己準備。反過來，用 Claude Code 做自家 IP 續作的團隊若被誤擋，官方表示可以回報。

Roblox 第三季：營收增 16%、bookings 跌 12%，前 100 大遊戲逾八成用 AI 工具加速製作

營收年增 16% 到 16 億美元，但 bookings 年減 12%、日活躍用戶減 9%；股東信強調幾乎全由 AI 做出的遊戲已打進同時在線前 20 名，手機 AI 建造功能 Build 在四國 alpha 階段就有 50 萬人發佈 7 萬款遊戲。

點評執行長的說法是「人人都能做遊戲時，關鍵是分發與發現」——對 UGC 創作者而言，產量暴增代表單靠作品被看見會更難，社群經營與曝光策略得提前布局。

產業動態

SAG-AFTRA 以近 95% 通過電視動畫配音新合約：四年加薪 12.6%，AI 保護再加強

美國演員工會會員以 94.95% 票數批准與製片方 AMPTP 的電視動畫及有線電視動畫合約，效期到 2030 年 6 月，內容包括加薪 12.6%、更強的 AI 使用保護與重播酬勞。

點評配音是 AI 聲音複製衝擊最直接的工種，美國動畫配音已連續兩版合約把 AI 條款寫進去；台灣團隊若要用 AI 配音或與海外配音員合作，「事先同意＋另計報酬」就是對方預期的行規。

AWN · 2026-10-30

產業動態・台灣

文策院 TCCF 創意內容大會 11 月登場：251 名國際買家、韓國成最大宗，跨國合製提案破六成

今年市場展買家來自 28 個國家與地區，韓國取代法國成最大宗；提案大會中台灣主導或參與的跨國合製佔比突破六成，四個專場各設逾 3 萬美元大獎，期間文策院也將與 Wētā FX 舉辦發布會回應 AI 趨勢。

點評買家結構轉向韓國、提案六成是跨國合製，代表台灣內容進國際市場「一開始就找海外夥伴」已是主流路徑；有動畫或影視企劃的團隊，Wētā FX 那場發布會值得追，看 AI 如何先從特效後製切入。

高雄

打狗祭壓軸「V FUTURE PARTY」：11 位台灣 VTuber 海音館接力開唱，近萬人到場

10/31 在高雄流行音樂中心海音館，春魚創意、子午計畫、箱箱 The Box 三個台灣 VTuber 團隊共 11 位虛擬偶像分三場演出；製作方新月映像斥資逾千萬元建兩座動態捕捉棚、架設超過 100 台攝影機，讓最多 6 位虛擬偶像同台。

點評多人同台的動捕規模才是這場演出的真正門檻——兩座動捕棚、上百台攝影機加上臉部捕捉，是目前台灣 VTuber 現場演出成本與技術最具體的一組公開數字。
