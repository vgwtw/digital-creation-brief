Adobe MAX 2026：Creative Agent 進駐全線 Creative Cloud，並開放本機 MCP 讓外部 AI 代理直接改你的專案檔

Adobe 11/10 在邁阿密 MAX 大會發表年度更新：能用口語交辦多步驟任務的 Adobe Creative Agent 擴大到 Creative Cloud 與 Firefly；Photoshop 加入 Relight 重新打光，Premiere 加入專業調色的 Color Mode 與影片物件移除；Firefly 則擴張成集合影片、音訊、圖像工具與多家外部模型的「AI 創作工作室」。最值得注意的是 Adobe 預告「本機 MCP 整合」，讓使用者慣用的第三方 AI 代理（如 ChatGPT、Claude、Gemini）能直接修改 Photoshop、Illustrator、Premiere、After Effects 的原生專案檔。昨天的 Disney 結盟是這場大會的客戶面，今天這則是產品面。

點評重點不是又多幾個生成功能，而是 Adobe 承認創作者已經在用別家的代理：開放 MCP 之後，「用哪個 AI」和「用哪套軟體」正式脫鉤。團隊現在就可以盤點哪些重複工序（批次改尺寸、整理素材、套版）適合交給代理；但 Adobe 自己也說開放範圍還在摸索，正式流程先別押寶。

Sony 取消服務型射擊遊戲《Fairgames》：測試留存未達標，Haven Studios 不裁員、轉為支援其他工作室

據 Bloomberg 報導，Sony 取消 2023 年公布的搶劫題材服務型射擊遊戲《Fairgames》；內部信說近期測試的玩家回饋與留存「未達設定目標」，並提到 PvP 射擊市場環境艱困。開發商 Haven Studios 不裁員，改為支援其他 PlayStation 工作室。

點評繼《Concord》收攤、《戰神》與《最後生還者》的服務型企劃取消後，Sony 的服務型佈局又少一塊。對美術與外包團隊的提醒：公布三年的專案仍可能在一次測試後歸零，接案時別把產能全押在單一長期專案上。

產業動態

萬代南夢宮解散《Unknown 9: Awakening》開發商 Reflector，將認列約 2,100 萬歐元損失

萬代南夢宮宣布解散並清算 2020 年收購的蒙特婁工作室 Reflector Entertainment，預計在本財年第三季認列約 2,100 萬歐元特別損失；該工作室的跨媒體新 IP《Unknown 9: Awakening》2024 年上市後銷售不如預期，此前已兩度裁員並取消整個系列。

點評上週本刊才提過「被收購的工作室三分之一已關門」，這就是活例子。一開始就把遊戲、小說、漫畫、Podcast 全鋪開的跨媒體 IP，在第一款作品沒站穩時反而放大損失——做原創 IP 的團隊，先把一個載體做成再談宇宙。

3D・遊戲引擎

Unreal Engine 5.9 預覽版釋出：Epic 稱這是第一個「主要靠 AI 代理群打造」的引擎版本

Epic 為 11/12–15 的 AI MegaJam 在約一週內趕出 UE 5.9 預覽版：少數工程師指揮成群 AI 代理，把 UE6 開發分支的 AI 工具移植回來，並重新支援 Web 平台（WebAssembly＋WebGPU）；內容還包括 Unreal MCP、Unreal Assistant、Lumen World Cache 與 Nanite 剔除改進。

點評兩個看點：一是引擎開始內建 MCP 與 AI 助手，和 Adobe 同一天走上同一條路；二是 Epic 坦承部分代理寫的程式碼還在清理、Web 渲染器只是原型。想試可以，但請用專案副本測，別拿正式專案升級。

創作者經濟

X 推出內建「切片」功能：剪片的人和原作者都能依觀看數分潤

X 推出內建 clipping 工具，使用者可直接從站上影片擷取片段、加上自己的評論再發文，每支短片都會標示「Clip from」並連回原影片；X 表示原創作者與剪輯者都能透過 Original Content Rewards 計畫依觀看數獲得收益。

點評「切片」原本是創作者自己花錢請人做的行銷手法，現在平台把它做成內建功能，還附上回連與分潤。有長影片的團隊可以留意：在 X 上被別人切片不再只是被搬運，而可能是有署名、有收入的擴散管道——不過分潤僅限符合資格的帳號。

動畫・台灣

幾米首部動畫影集《小蝴蝶小披風》11/14 首播：導演親繪上千張分鏡，每集 3 分鐘

改編自幾米 2005 年同名繪本的動畫影集由原金動畫製作、王世偉執導，前期手繪超過一千張分鏡，製作中每集再提出上百幀手繪修改回饋；配樂由金曲製作人陳建騏與陳宜萱操刀，11/14 起首播。

點評在一片 AI 提速的新聞裡，這是另一種做法：短篇幅、導演逐幀把關、音樂與音效刻意模糊界線。台灣繪本 IP 動畫化的案例不多，做 IP 改編或兒童內容的團隊，值得看它怎麼把靜態畫風轉成動態。
